4. Subgraph booking_flow — đặt lịch khám

6. Đặt lịch bằng giọng nói — luồng end-to-end

Mỗi lần interrupt() trả về UI rồi kết thúc request; checkpoint lưu trong Postgres. Lựa chọn của người dùng đi vào lại qua POST /resume với Command(resume=...).

sequenceDiagram
  autonumber
  actor U as Người dùng
  participant UI as UI
  participant API as FastAPI
  participant STT as faster-whisper
  participant G as LangGraph
  participant L as Claude (Bedrock)
  participant DB as Backend / Postgres

  U->>UI: 🎙 "Đặt lịch khoa PHCN
thứ Ba tuần sau buổi sáng"
  UI->>API: POST /stt/transcribe (audio)
  API->>STT: transcribe(vi)
  STT-->>API: text + xác suất
từng từ + cờ
  API-->>UI: transcript, tô sáng đoạn nghi ngờ
  U->>UI: duyệt / sửa transcript
  UI->>API: POST /chat/{thread}/messages
  API->>G: ainvoke(transcript đã duyệt)
  G->>G: ingest → guard_input
→ classify = book_appointment
  G->>L: extract_booking (structured output)
  L-->>G: BookingRequest + evidence
  G->>G: resolve_datetime → 03/11/2026 sáng
validate_booking ✓
  G->>DB: get_available_slots(khoa, 03/11 sáng)
  DB-->>G: 3 slot (slot_id do backend sinh)
  G-->>API: interrupt(present_slot_options)
  API-->>UI: danh sách slot đánh số
  U->>UI: 🎙 "cái thứ hai"
  UI->>API: POST /resume {selection}
  API->>G: Command(resume=...)
  G->>G: match_selection → option 2 ∈ offered_slots ✓
  G-->>API: interrupt(present_booking_draft)
  API-->>UI: bản đọc lại: "Thứ Ba, 03/11/2026,
09:30 – BS. … – Khoa PHCN"
  U->>UI: "xác nhận"
  UI->>API: POST /resume {confirm}
  API->>G: Command(resume=confirm)
  G->>DB: create_appointment(slot_id, idempotency_key)
  alt slot vừa bị người khác đặt
    DB-->>G: error conflict
    G->>DB: search_slots lại (tối đa 1 lần)
  else thành công
    DB-->>G: ok, appointment_id
    G->>DB: đọc lại appointment
    DB-->>G: khớp slot & giờ ✓
  end
  G->>L: respond (chỉ diễn đạt
dữ liệu đã xác minh)
  G-->>API: kết quả + căn cứ
  API-->>UI: "Đã đặt lịch … (mã lịch hẹn …)"

7. Dữ liệu (PostgreSQL)

ID và timestamp do database sinh. Hai bảng ghi đều có idempotency_key UNIQUE; appointments thêm partial unique index trên slot_id.
